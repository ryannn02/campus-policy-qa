## 数据口径说明

- 登记表 `meta/documents.csv` 共 309 行：
  - `effective`（生效）：266 份；
  - `archived`（已被新版替代、保留追溯）：10 份；
  - `excluded`（正文为空的网页壳，已剔除）：33 份。
- 266 份 effective **全部**解析成功进入 `chunks.jsonl`（4278 块），解析失败 0 条。
- 扫描件比例：1 / 266 ≈ 0.4%，远低于需求「扫描件 ≤20%」上限。

## 引用定位字段的覆盖现状

| 字段 | 缺失 chunk 数 | 根因 |
| --- | --- | --- |
| `page` | 约 1588 / 4278 | 仅 PDF 能提取页码；HTML 正文页 / Word（doc/docx）/ 人工整理 txt 天然无页码概念 |
| `source_url` | 约 105 / 4278 | 全部来自「人工整理」txt，为手动归纳件，无官网来源 URL |

- PDF 的 chunk 页码 100% 完整（含 OCR 扫描件）；page 缺失集中在前端展示时
  以「章节 / 标题」兜底，不阻断引用跳转。
- 以上缺失属结构性（非解析错误），非 PDF 来源无法补页码、手动件无法补 URL，
  已在评测集与前端契约中按「可选字段」处理（`docs/web_api_contract.md`）。
