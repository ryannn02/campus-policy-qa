## 六、完成过程中的问题与各组员解决方法

### 成员 A（数据与解析）
| 问题 | 解决方法 |
| --- | --- |
| 2 份扫描件 PDF 无文字层，不入库 | `ingest.py` 加 **RapidOCR 回退**：PDF 文字层 <120 字判定扫描件，自动逐页 OCR，页码按物理页保留 |
| 24 个未登记遗留文件（招生/通知/重复/非制度） | 分四类处置：移出 21 个到 `data/removed/`、补登记 3 份制度文件 |
| `ingest` 在 IDE 里运行全部「文件找不到」，chunks 被清空 | 组长修复：路径锚定 `ROOT_DIR`（原依赖工作目录）+ **原子写**（临时文件 rename）+ 全部失败保留旧文件 + 逐条进度输出 |

### 成员 B（检索与模型链）
| 问题 | 解决方法 |
| --- | --- |
| Recall@5 = 0.733 未达标 | 先做**向量模型选型评估**（bge-m3 本机构建 ~1.8h 太慢 → 结论暂不切换，见 `docs/embedding_eval.md`）；改用 **BM25（字符 2-gram）+ 向量多路召回 + RRF 融合**，扫参 `per_doc=3 / bm25_top_k=10` → **0.802** |
| 同主题条款多版本挤占 top-5 | **跨文档同主题去重**（difflib 重合 ≥0.85 只留高分代表）→ Recall@5 **0.819** |
| v4 规则「只引用最贴近问题的一版」让引用过保守，grounded 0.776→0.681 | 组长建 **v5**：删除该规则、恢复「关键论断宁多勿漏」，保留 v4 拒答强化 → grounded **0.810** |

### 成员 C（拒答逻辑与评测）
| 问题 | 解决方法 |
| --- | --- |
| refuse_failure_rate 0.200 未达标（15 条「天气/餐厅/履历」类误答） | 服务层**领域相关性前置判定**（`_DOMAIN_KEYWORDS` 约 70 个制度关键词 + `domain_score_threshold=0.68` 双条件拒答）+ 任务型请求/输出语言/歧义拦截 → 0.019；v4/v5「制度库外内容置空」→ **0.000** |
| gold 标注仅 71.6%，grounded 口径不可靠 | gold 补全至 **100%**；再做**多版本标注**（162→273 元素，difflib ≥0.90 找条款重复版本）消除「第六/九条」类假阴性 |
| grounded_rate 0.722 未达标 | 与 B 协同：多路召回 + 多版本 gold + v5 → **0.810** |
