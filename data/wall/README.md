# 校园墙 → 问题集

这里放的是**从校园墙提炼出来的问题**，不是原始帖子，也不含任何发帖人信息。

## 为什么不是「导入 CSV」

CSV 是二手整理结果：谁整理的、按什么口径筛的、有没有漏，都无法追溯。
这里改成直接从墙抓原始内容，用同一套规则提炼，过程可复现：

```
校园墙原始内容
  → 去噪（CQ 码 / @ / 链接 / 话题 / 投稿开场白）
  → 切句
  → 问句信号过滤（吗 / 呢 / 怎么 / 几点 / 多少 / 哪里 …）
  → 脱敏（手机号 / 学号 / QQ / 微信 / 身份证 / 姓名）
  → 统一问号
  → 2-gram Jaccard 去重
  → 类目归类（餐饮 / 快递 / 校园卡 / 宿舍 / 图书馆 / 网络 / 医疗 / 交通 / 学习 / 其他）
  → data/wall/questions.jsonl
```

## 命令

```bash
# 有接口时（或 .env 里配 WALL_SOURCE）
python -m scripts.crawl_wall --source "<校园墙接口>" --limit 300

# 只有落盘的原始内容时，离线验证提炼质量
python -m scripts.crawl_wall --raw-jsonl data/wall/raw_sample.jsonl --dry-run
```

## 隐私边界

- 只保留「问题」与「回答所需的信息」，**不保留**昵称、QQ 号、学号、手机号、头像、时间线；
- 脱敏在判问句之前执行，未命中的句子不会进入下游；
- `report.json` 只记录数量与类目分布，不记录原文。
